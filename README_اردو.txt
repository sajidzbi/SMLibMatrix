ISLMS — گِٹ ہب پیجز پر چلانے کی ہدایات
=======================================

فائلیں (سب ایک ہی فولڈر میں، اسی ترتیب سے):
  index.html
  sw.js
  manifest.webmanifest
  .nojekyll
  fonts/JameelNooriNastaleeq.woff
  icons/ (پانچ تصویریں)

۰) پہلے اپنے کمپیوٹر میں دیکھیں (گِٹ ہب پر ڈالنے سے پہلے)
  - زپ کو کسی فولڈر میں extract کریں (زپ کے اندر سے نہیں، پہلے extract)۔
  - فولڈر میں index.html پر ڈبل کلک کریں؛ پروگرام براؤزر میں کھل جائے گا اور فونٹ بھی لگ جائے گا۔
  - اس طرح کھولنے پر "انسٹال" کا بٹن اور خودکار اپ ڈیٹ نہیں چلتے (یہ صرف گِٹ ہب کے لنک پر چلتے ہیں)، باقی سب کچھ ویسا ہی چلتا ہے۔
  - اس صورت میں ڈیٹا الگ ہوتا ہے، گِٹ ہب والے لنک کا ڈیٹا اس میں نہیں آتا۔ تجربے کے لیے "Quick Start / Demo Data" استعمال کریں۔
  - پروگرام میں Help ▸ اوپر "Program Version" میں ورژن لکھا ہوتا ہے۔
  - جب تسلی ہو جائے تب گِٹ ہب پر اپ لوڈ کریں۔

۱) پہلی بار اپ لوڈ
  - گِٹ ہب پر نئی repository بنائیں (Public)۔
  - تمام فائلیں اور فولڈر (fonts اور icons سمیت) اپ لوڈ کریں۔
  - Settings ▸ Pages ▸ Branch: main / root ▸ Save۔
  - چند منٹ بعد پتہ ملے گا: https://آپکا-نام.github.io/repository-نام/

۲) انسٹال
  - لنک کھولیں؛ اوپر بڑا "پروگرام انسٹال کریں" کا بٹن آئے گا۔ دبائیں۔
  - انسٹال ہونے کے بعد وہ بٹن دوبارہ نہیں آتا۔
  - آئی فون میں: Safari ▸ Share ▸ Add to Home Screen۔
  - فونٹ (تقریباً 8.8 MB) پہلی بار ایک ہی دفعہ ڈاؤن لوڈ ہو کر محفوظ ہو جاتا ہے، پھر پروگرام تیز چلتا ہے۔

گِٹ ہب پر اپ لوڈ کے بعد تصدیق:
  - اپنی سائٹ کے لنک کے آخر میں /sw.js لگا کر کھولیں؛ اوپر VER = 'islms-32' لکھا ہو تو نئی فائلیں پہنچ گئیں۔
  - اگر پرانا نمبر نظر آئے تو فائلیں مین فولڈر (root) میں نہیں گئیں، یا گِٹ ہب پیجز نے ابھی نیا نہیں بنایا۔
  - فائلیں repository کے سب سے اوپر والے مقام میں ہونی چاہئیں، کسی اور فولڈر کے اندر نہیں۔

۳) نیا ورژن جاری کرنا (خودکار اپ ڈیٹ)
  - index.html میں تبدیلی کریں۔
  - index.html کے شروع میں یہ سطر ڈھونڈیں اور نمبر بڑھا دیں:
        <meta name="app-version" content="32">
  - sw.js کی پہلی سطروں میں بھی نمبر بڑھا دیں:  const VER = 'islms-32';
  - دونوں فائلیں گِٹ ہب پر دوبارہ اپ لوڈ کریں (replace)۔
  - جن کے پاس پروگرام انسٹال ہے ان کا پروگرام کچھ دیر میں خود نیا ہو جائے گا (جب وہ ٹائپ نہ کر رہے ہوں)۔
  - ان کا سارا ڈیٹا ان کے اپنے آلے میں محفوظ رہتا ہے، اپ ڈیٹ سے ضائع نہیں ہوتا۔

نوٹ: ہر کمپیوٹر/فون کا ڈیٹا اسی آلے کے براؤزر میں رہتا ہے؛ Backup Data کا بٹن باقاعدگی سے استعمال کریں۔
